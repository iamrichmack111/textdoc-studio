# Scene types

| Type | Best use | Treatment |
|---|---|---|
| Narration | Main explanatory prose | Cinematic assigned image |
| Chapter | Major section break | Large typography; keep concise |
| Quote | Attributed quotation | Quote-focused typography |
| Punch | Dramatic beat | Short typography, ideally 3–15 words |
| Words | Concepts/keywords | Sequential word treatment |
| Document | Manuscripts/notices/pages | Evidence framing and legibility |
| Map | Geographic evidence | Map-oriented evidence scene |
| B-roll | Atmosphere/coverage | Visual-first cinematic scene |
